What the input_actions plugin does not do yet, in the order planned.

1. Runtime rebinding, saved to an override file.
2. Control schemes.
3. A generated enum of the actions.
4. Hold and tap triggers.
5. Touch and on-screen controls.
6. Several players, each with their own devices.
