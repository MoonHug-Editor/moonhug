---
title: "CanvasRenderer"
description: "Marks a UI node as drawing its graphic"
weight: 120
tags: ["engine", "ui", "components"]
path: engine/components
---

Marks a UI node as drawing. What it draws is the node's graphic, such as an Image or a Text. Disabling it hides the graphic. A Button's tint is a runtime colour on it, never saved.
