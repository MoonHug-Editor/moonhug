What the text plugin does not do yet. How it works is in [Layout](concepts/Layout.md).

## Open

- Rich text tags.
- Per-character effects, gradients and glow.
- Page, linked and scroll overflow modes.
- Shaping, for scripts that join or reorder glyphs.
- Multi-channel distance fields, which keep corners sharp at large sizes. The artifact format has room for a channel count.
